## ⚠️ サイトが表示されない場合の重要な注意点

### **間違ったアップロード方法 ❌**
```
www/
└── shibuya-pilates/        ← フォルダごとアップロードすると表示されない！
    ├── index.html
    └── ...
```

この場合、`https://あなたのドメイン/shibuya-pilates/` でしかアクセスできません。

### **正しいアップロード方法 ✅**
```
www/                         ← ここに直接ファイルを置く
├── .htaccess
├── index.html
├── cushion.html
└── ...
```

**重要:** `shibuya-pilates` フォルダの**中身だけ**をアップロードしてください！

## 🚀 アップロード手順（さくらサーバー）

### 方法1: FTPソフトを使う場合（推奨）

1. **ZIPファイルを解凍**
   - `elan-pilates-FINAL.zip` を解凍
   - `shibuya-pilates` フォルダが作成されます

2. **FTPソフトでサーバーに接続**
   - FileZilla、Cyberduckなどを使用
   - ホスト：さくらサーバーのFTPサーバー名
   - ユーザー名：FTPアカウント
   - パスワード：FTPパスワード

3. **ファイルをアップロード（重要！）**
   - サーバー側で `public_html/` または `www/` ディレクトリを開く
   - **`shibuya-pilates` フォルダを開いて、中身のファイルだけを選択**
   - 選択したファイルを `www/` に直接ドラッグ&ドロップ
   - **フォルダごとアップロードしないこと！**

4. **アップロード完了後の確認**
   - FTPで `/www/index.html` が存在するか確認
   - `/www/.htaccess` が存在するか確認
   - ブラウザで `https://あなたのドメイン/` にアクセスして表示を確認

---

### 方法2: さくらのファイルマネージャーを使う場合

1. **さくらのコントロールパネルにログイン**
   - https://secure.sakura.ad.jp/rscontrol/

2. **ファイルマネージャーを開く**
   - 「ファイルマネージャー」をクリック

3. **ZIPファイルをアップロード**
   - `www` フォルダに移動
   - 「アップロード」ボタンをクリック
   - `elan-pilates-upload.zip` を選択してアップロード

4. **ZIPファイルを解凍**
   - アップロードした `elan-pilates-upload.zip` を選択
   - 「解凍」をクリック

5. **ファイルを移動**
   - 解凍された `shibuya-pilates` フォルダ内のファイルを
   - `www` フォルダの直下に移動
