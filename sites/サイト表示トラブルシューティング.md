# elanpilates.tokyo サイト表示トラブルシューティング

## 🚨 現在の問題

サイト https://elanpilates.tokyo/ にアクセスできない状態です。

## ✅ 確認・修正手順

### 1. ファイルが正しい場所にアップロードされているか確認

**FTPまたはファイルマネージャーで確認:**

```
/home/アカウント名/www/
├── .htaccess           ← これが必須！
├── index.html          ← これが必須！
├── cushion.html
├── guide.html
├── design-system/
│   └── index.css
└── images/
    └── menu.png
```

**❌ 間違った配置（よくあるミス）:**

```
/home/アカウント名/www/
└── shibuya-pilates/    ← これだと表示されない
    ├── index.html
    └── ...
```

もし `shibuya-pilates` フォルダがある場合：
1. `shibuya-pilates` フォルダを開く
2. 中のファイルを全選択
3. `www` フォルダに直接移動
4. `shibuya-pilates` フォルダを削除

---

### 2. SSL証明書の設定（さくらサーバー）

現在SSL証明書のエラーが出ています。

**さくらサーバーでSSL設定:**

1. **さくらコントロールパネルにログイン**
   https://secure.sakura.ad.jp/rscontrol/

2. **SSL証明書の設定**
   - 左メニュー「ドメイン/SSL」をクリック
   - 「ドメイン/SSL」→「証明書」タブ

3. **無料SSL（Let's Encrypt）を設定**
   - 「無料SSLの設定へ進む」をクリック
   - `elanpilates.tokyo` を選択
   - 「無料SSLを設定する」をクリック
   - 設定完了まで数分〜数時間かかります

4. **HTTPSリダイレクト設定**
   SSL証明書が有効になったら、`.htaccess` ファイルに以下を追加：

```apache
# HTTPSリダイレクト
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteCond %{HTTPS} off
    RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [R=301,L]
</IfModule>
```

---

### 3. ドメイン設定の確認

**さくらサーバーでドメイン設定:**

1. コントロールパネル → 「ドメイン/SSL」
2. `elanpilates.tokyo` が正しく設定されているか確認
3. 「マルチドメイン」として設定されているか確認
4. 指定フォルダが `/` または空欄になっているか確認

**❌ 間違った設定例:**
- 指定フォルダ: `shibuya-pilates` ← これだと `/shibuya-pilates/` でしかアクセスできない

**✅ 正しい設定:**
- 指定フォルダ: 空欄 または `/`

---

### 4. .htaccess ファイルの確認

FTPで `/www/.htaccess` ファイルを開いて、以下が含まれているか確認：

```apache
# 文字コード設定
AddDefaultCharset UTF-8

# ファイルの文字コードを明示的に指定
<IfModule mod_mime.c>
    AddType text/html .html .htm
    AddType text/css .css
    AddType application/javascript .js
    AddCharset UTF-8 .html .htm .css .js
</IfModule>
```

---

### 5. DNSの確認（念のため）

**コマンドプロンプトまたはターミナルで確認:**

```bash
nslookup elanpilates.tokyo
```

または

```bash
dig elanpilates.tokyo
```

正しいIPアドレスが返ってくるか確認してください。

## 🔧 問題が解決しない場合

### A. ファイルマネージャーで直接確認

1. さくらコントロールパネルにログイン
2. ファイルマネージャーを開く
3. `www` フォルダの中身を確認
4. `index.html` が直下にあるか確認

### B. FTPソフトで再アップロード

1. サーバー上の `www` フォルダの中身を全て削除（バックアップを取ってから）
2. `elan-pilates-GTM.zip` を解凍
3. `shibuya-pilates` フォルダの**中身だけ**を選択
4. `www` フォルダに直接アップロード

### C. さくらサーバーサポートに問い合わせ

以下の情報を伝えてください：
- ドメイン: `elanpilates.tokyo`
- 問題: サイトが表示されない、SSL証明書エラーが出る
- 確認したこと: ファイルは `/www/` 直下にアップロード済み
