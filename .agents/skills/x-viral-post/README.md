# X Viral Post Creator Skill

Xでバイラルになるための科学的手法に基づいた投稿作成スキル。1000万以上のインプレッションを生み出した実証済みのフレームワークを使用します。

## 概要

このスキルは、以下の3つの原則に基づいてX投稿を最適化します：

1. **教育（Education）**: テイストの養成、インスピレーションバンク、ボイスのキュレーション
2. **アーキテクチャ（Architecture）**: フォーマット選択、ツイートフレーミング、品質重視
3. **配布（Distribution）**: インプレッション最適化、エンゲージメント、リポスト活用

## 使い方

### 基本的な呼び出し

```
/x-viral-post スタートアップの失敗から学んだ5つの教訓について投稿を作成して
```

### 具体的な指示と一緒に

```
/x-viral-post
テーマ: AIプロダクト開発で失敗した話
ターゲット: スタートアップ創業者、エンジニア
トーン: 正直で教訓的
フォーマット: スレッド形式
```

### 他のスキルとの連携

```
まず /x-researcher でバイラル投稿を分析して、
その後 /x-viral-post で投稿を作成
```

## 特徴

### 🎯 科学的アプローチ
- エンゲージメント乗数を考慮（いいね+1、ブックマーク+10、コメント+27）
- ツイートフレーミング最適化
- 配布戦略の提案

### 📝 4つのフォーマット対応
1. **ステートメント**: 280文字未満の短文
2. **ロングフォームツイート**: ミニ記事
3. **スレッド**: 連鎖ツイート
4. **記事**: X Articleの新フォーマット

### 🚀 配布戦略込み
- エンゲージメントプランの提案
- リポストタイミングと引用文案
- コメント返信の推奨事項

## スキルが提供するもの

1. **投稿案（複数バリエーション）**
   - 異なるフレーミング
   - 異なる最適化ターゲット
   - 異なるトーン

2. **フレーミング分析**
   - 最初の280文字の評価
   - 「もっと見る」直後の情報配置

3. **配布戦略**
   - エンゲージメント計画
   - リポスト戦略
   - タイミング推奨

## 原則

### ✅ すべきこと
- ユニークな経験からの価値提供
- 品質重視の投稿作成
- フレーミングの最適化
- エンゲージメント戦略の実行

### ❌ すべきでないこと
- 量を重視して品質を犠牲にする
- フレーミングを軽視する
- エンゲージメントを無視する
- 抽象的で曖昧な投稿を作る

## 連携スキル

- **x-researcher**: トピックのリサーチ、バイラルツイートの分析
- **x-copywriter**: 複数の投稿バリエーションの作成
- **x-marketer**: 最終的な投稿の戦略的ブラッシュアップ

## 例

### 入力
```
/x-viral-post 1ヶ月で6000人フォロワー獲得した方法について投稿したい
```

### 出力
スキルは以下を提供します：
1. コンテキストを収集するための質問
2. 最適なフォーマットの提案
3. 2-3の投稿バリエーション
4. フレーミング分析
5. 配布戦略（エンゲージメントとリポスト計画）

## 重要なマインドセット

> **「打たないシュートは100%外れる」**
>
> バイラルは科学です。このフレームワークに従い、反復を重ねれば、必ず成果が出ます。
